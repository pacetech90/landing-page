# Polimorf — UI Polimorfisme Gelap

Landing page bertema **Dark Polymorphism** dengan antarmuka gelap yang elegan, efek morfosis organik, dan elemen glassmorphism interaktif.

## Fitur

- **Morphing Blobs** — Bentuk organik yang berubah-ubah secara dinamis di latar belakang
- **Glassmorphism Cards** — Panel kaca transparan dengan efek blur dan floating animasi
- **Particle Network** — Jaringan partikel interaktif di canvas latar
- **Dark Theme** — Palet warna gelap luar angkasa dengan aksen ungu & cyan
- **Counter Animation** — Animasi angka statistik yang berjalan saat di-scroll
- **Smooth Reveal** — Elemen muncul bertahap dengan efek scroll
- **Fully Responsive** — Tampilan optimal di semua ukuran layar

## Teknologi

- HTML5
- CSS3 (Animasi, Glassmorphism, Flexbox/Grid)
- Vanilla JavaScript (Canvas API, Intersection Observer)

## Cara Menggunakan

1. Letakkan folder ini di root web server (misal: `C:\wamp64\www\dark-poly-landing`)
2. Akses melalui browser: `http://localhost/dark-poly-landing/`

Atau buka langsung file `index.html` di browser modern.
